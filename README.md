# 🎸 StartSom

O StartSom é um site educativo voltado para violão, oferecendo conteúdos explicativos, tutoriais e dicas sobre o instrumento. Além disso, o projeto conta com uma lista de tarefas para ajudar os usuários a acompanharem seu aprendizado.

# 🧩 Funcionalidades

📖 Explicações e tutoriais sobre violão.

 ✅ Lista de tarefas para acompanhamento de estudos.

 🖥️ Interface simples.


# 🛠️ Tecnologias Utilizadas

React

LocalStorage
